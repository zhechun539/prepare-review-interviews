# 公司、岗位与小红书研究

## 来源分层

- A 级：公司官网、官方账号、官方招聘页、监管/工商公开信息、产品文档。
- B 级：权威媒体、行业协会、可靠数据库、招聘平台的公司与岗位页面。
- C 级：小红书、脉脉、论坛、匿名面经、员工或候选人公开分享。

A/B 级用于公司事实；C 级用于发现问题、体验模式和待验证风险。

## 小红书检索

建议搜索：

- `公司全称 + 面试`、`品牌名 + 面试`；
- `公司名 + 目标岗位`、`公司名 + 工作体验`；
- `公司名 + 加班/薪资/管理/避雷`；
- `岗位名 + 城市 + 面经`。

记录：标题、作者/账号、发布日期、链接、岗位/城市/时间、是否第一手、核心说法、支持或反驳它的其他来源。至少两个独立样本重复出现，才可写成“重复出现的反馈”；否则写“单一样本提及”。

## 浏览器限制

若公开页面无结果、要求登录或出现验证码，不绕过限制。用户明确指定浏览器时，按浏览器规则请用户在该浏览器登录；验证码必须由用户决定是否处理。无法核实时，在交付中写明“未获得可验证的小红书样本”。

## 引用

每项会影响面试判断的外部事实都附直接链接和日期。不要只放搜索结果页。用户生成内容用转述，不大段复制原文；避免暴露无关个人信息。
